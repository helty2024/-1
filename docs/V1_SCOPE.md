# V1 开发范围

> 本文档是 V1 开发、验收和需求变更的范围基线。

## 建设原则

- 保留当前微信小程序根目录和已有展示小样。
- 不移动 `app.js`、`app.json`、`pages`、`components`。
- V1 先建立正式后台、API、数据库、媒体存储、权限和审计基础。
- 业务展示内容最终由 Web 管理后台维护，不以小程序本地静态数据作为正式数据源。
- 新需求如果超出本文档范围，需要先确认版本归属后再进入开发。

## V1 包含

1. 企业展示
   - 企业形象
   - 公司简介
   - 品牌故事
   - 发展历程

2. 品牌背书
   - 资质证书
   - 检测报告
   - 企业荣誉
   - 合作案例
   - 媒体报道

3. 明星产品
   - 产品分类和列表
   - 产品卖点
   - 原料与工艺
   - 产品规格
   - 使用场景
   - 招商价值

4. 招商代理
   - 合作模式
   - 代理权益
   - 扶持政策
   - 合作流程
   - 常见问题

5. 投资合作
   - 项目介绍
   - 商业模式
   - 增长规划
   - 合作方向
   - 资源需求

6. 表单提交
   - 代理申请
   - 投资合作申请
   - 普通咨询
   - 动态表单字段
   - 可选附件上传

7. 线索管理
   - 查看、筛选和搜索
   - 分配负责人
   - 状态和等级管理
   - 跟进记录和下次跟进时间
   - 按权限导出

8. 媒体资料
   - 图片上传和管理
   - PDF、DOCX、XLSX 等资料上传和管理
   - 公开与私有访问级别
   - 媒体引用检查

9. 权限和审计
   - 管理员登录
   - 角色和权限
   - 菜单和接口权限
   - 敏感信息脱敏
   - 后台操作审计

## V1 不包含

- 购物车
- 在线订单
- 微信支付
- 库存管理
- 物流管理
- 佣金与分润结算
- 代理商独立账号体系

以上能力只做架构兼容性预留，不在 V1 创建业务页面、接口或数据表，不纳入 V1 验收。

## 当前阶段 A 范围

本阶段只完成基础设施和后台骨架：

- `api-server` NestJS 服务端基础能力；
- Prisma 首批数据模型、迁移和种子数据；
- MySQL、Redis、Nginx 和环境配置示例；
- `admin-web` Vue 3 管理后台登录页、主布局和模块占位页；
- 小程序上传忽略配置；
- 本地启动、数据库初始化和验收说明。

本阶段不将现有小程序页面切换到 API，不删除本地内容和线索原型。

## 范围验收

- 新增代码中不存在购物车、订单、支付、库存、物流、佣金业务模块。
- 微信开发者工具仍可直接打开仓库根目录。
- 后台和 API 目录不会进入小程序上传包。
- API 与后台可以独立安装、启动和构建。
- 数据库结构能够支持后续内容、产品、表单、线索、媒体、权限和审计模块开发。
