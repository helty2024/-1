# 管理员、权限与审计日志测试

## 一、入口

1. 登录管理后台 `http://localhost:5173`。
2. 点击左侧“账号与权限”，超级管理员应看到“我的账号、管理员、角色权限”三个页签。
3. 点击左侧独立菜单“审计日志”，进入只读审计页面。

## 二、新建角色

1. 打开“角色权限”，点击“新增角色”。
2. 填写角色编码、角色名称和用途说明。
3. 勾选该角色实际需要的权限并保存。
4. 返回列表，确认新角色及权限数量正确。

## 三、新建管理员

1. 打开“管理员”，点击“新增管理员”。
2. 填写登录账号、显示名称和初始密码。
3. 初始密码至少 10 位，必须包含大写字母、小写字母、数字和特殊字符。
4. 选择刚创建的角色并保存。
5. 使用新账号登录，确认左侧菜单只显示该角色有权访问的模块。

## 四、账号控制

1. 超级管理员可以编辑其他管理员的账号、显示名称和角色。
2. 点击“重置密码”，使用新密码重新登录，旧密码应失效。
3. 点击“停用”，该账号应立即无法登录；重新启用后可以恢复登录。
4. 当前登录账号不能停用自己，也不能在管理员列表中修改自己的角色。
5. 系统不允许停用或移除最后一个启用的超级管理员。

## 五、审计日志

1. 点击左侧“审计日志”。
2. 确认新增管理员、修改角色、重置密码、停用账号和线索导出均有记录。
3. 使用关键词、管理员、操作类型、业务模块和日期范围筛选，确认结果正确。
4. 点击任意记录的“查看详情”，确认操作前、操作后、IP、requestId 和客户端信息可查看。
5. 审计日志只能查看和筛选，不提供修改、删除入口。

测试管理员和角色不再使用时，可先停用管理员，再删除未被任何管理员使用的自定义角色。系统内置角色不可删除。
